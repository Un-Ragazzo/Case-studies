이메일 서명 생성기

수신자 언어에 맞게 이름의 표시 순서를 정한 뒤, 완성된 서명을 복사해 이메일 서명란에 붙여넣으세요.
로고는 자리표시자로 제공되므로, 붙여넣은 후 실제 이미지로 교체해야 합니다.

서명 정보

서명에서 먼저 강조할 이름입니다.

서명에서 두 번째로 표시할 이름입니다.

예: Product Manager, Software Engineer, Researcher

기본형

이름과 직함만 표시합니다.

연락처형

이름과 직함, 연락처를 함께 표시합니다.

Gmail 적용 방법

  1. 사용할 서명의 복사 버튼을 누릅니다.
  2. Gmail의 설정 → 모든 설정 보기 → 일반 → 서명에 붙여넣습니다.
  3. 로고 삽입 (크기:작게) 자리표시자 문구를 삭제합니다.
  4. 같은 위치에 Gmail의 이미지 삽입 기능으로 로고를 넣고 크기를 작게로 선택합니다.
